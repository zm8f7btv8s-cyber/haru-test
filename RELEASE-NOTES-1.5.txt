하루 1.5 음성 기능 테스트판 (2026-11-12)

기준: 하루 1.4 통합 테스트 ZIP. 정규 haru-new는 수정하지 않음.

변경 사항
- 음성 인식 완료 후 기존 '음성 등록 종류 선택' 화면에서 인식 문장을 바로 수정 가능
- 문장 수정 시 날짜/시간/제목/장소 미리보기 재분석
- 원문 복원 버튼 제공
- 기존 일정으로 등록/할 일로 등록 선택과 최종 저장 전 편집 화면 유지
- 사용자가 수정하고 실제 저장한 문장의 전후 차이를 브라우저에 보관, 다음 인식 시 보정 후보로 활용
- 날짜/시간이 불확실하면 미리보기에서 확인 필요 표시
- 디자인의 주요 레이아웃과 일정 데이터 저장 키 유지
- 추가 유료 API 없음

주의
- 개인화 사전은 단순한 문자열 치환이며 AI 학습이 아님. 일부 문맥에서는 부정확할 수 있음.
- 인식 자체의 정확도는 iOS 브라우저 음성 인식 엔진에 의존함.
- 개인화 사전은 해당 브라우저 localStorage에 저장되며 기기 변경/데이터 삭제 시 사라질 수 있음.
- 실제 아이폰 음성 입력과 UI는 기기에서 별도 검증 필요.
- 기존 자동 회귀 테스트는 음성 엔진의 문장 분석만 검증하며 UI와 개인화 보정까지 검증하지 않음.
