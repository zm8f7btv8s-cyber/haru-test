하루 2.0 AI 개인비서 기반 테스트판 (2026-11-13)

1. ZIP 압축을 풀고 파일들을 GitHub Pages 테스트 저장소의 루트에 업로드하세요.
2. 정규 haru-new 저장소는 수정하지 마세요.
3. 처음에는 무료 기본 분석 모드로 작동합니다. AI 모델 연결은 아직 배포/설정되지 않았습니다.
4. 유료 AI를 연결하려면 server/worker.js를 Cloudflare Workers에 별도로 배포하고
   OPENAI_API_KEY 비밀키, ALLOWED_ORIGIN(테스트 GitHub Pages의 정확한 출처),
   DAILY_LIMIT KV 바인딩을 설정해야 합니다. 앱의 설정에 HTTPS Worker /analyze URL을 입력하고
   외부 전송에 동의하면 AI 분석을 시도합니다.
5. ChatGPT Plus 요금과 API 비용은 별개입니다. 이 샘플의 KV 횟수 제한은
   분산 환경에서 엄격한 비용 상한이 아닙니다. 실제 운영 전 제공업체 사용량/예산 알림과
   인증/남용 방지 정책을 추가하세요. 공개된 Worker URL은 제3자가 호출할 위험이 있습니다.
6. 데이터 저장 키는 기존 테스트판 haru.fresh.test.v1 을 그대로 사용합니다.
   다른 앱과 같은 GitHub Pages 출처에서 실행하면 저장 공간을 공유할 수 있으니
   테스트 전 설정 > 내 데이터 백업(JSON)을 사용하세요.
7. '등록 화면에서 수정'을 누른 뒤 반드시 저장 내용을 확인하세요. AI는 자동 저장/삭제하지 않습니다.
8. 이번 테스트는 홈 화면, 문자/음성 요청 입력, AI 연동 준비, 기존 등록 폼 연동의 기반 구현입니다.
   실제 서버 배포와 아이폰 Safari 실기기 검증은 아직 완료되지 않았습니다.
